# Proyecto

## Nombre
paradasi-lists

## Propósito

Aplicación web personal para crear, organizar y administrar colecciones de elementos de diferentes temáticas, como películas favoritas, libros, videojuegos, música, lugares por visitar y cualquier otra categoría que el usuario desee.

El objetivo es ofrecer un espacio centralizado donde guardar, consultar y organizar las cosas que nos gustan o que queremos recordar.

## Alcance
- Autenticación de usuarios.
- CRUD de colecciones.
- CRUD de elementos.
- Gestión de imágenes.
- Favoritos y calificaciones.
- Búsqueda global.
- Filtros y ordenamiento.
- Dashboard.
- Interfaz responsive.
- Exportación de datos.

## Funcionalidades futuras

- Integración con APIs externas para obtener información e imágenes de películas, libros y otros contenidos.
- Importación desde archivos CSV.
- Compartir colecciones.
- Colecciones públicas.
- Campos personalizados.
- Estadísticas avanzadas.
- Recomendaciones mediante IA.

## Usuarios
- **Usuario**: Es el usuario normal de la aplciación que se rgistra con una cuenta de googel y usa la aplicación.

## Glosario
| Término | Definición |
|---|---|
| Lista | Una colección de elementos con su descripción |
| Etiqueta | Se usa para etiquetar una colección lo cual hace más fácil la busqueda y la administración |

## Stack
TypeScript, Svelte 5, SvelteKit, Tailwind CSS, Drizzle ORM con SQLite/libSQL y Better Auth. npm es el gestor de paquetes indicado por los scripts y el lockfile.
